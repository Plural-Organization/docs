**Plural** is the shared room for your coding agent. One person — the **host** — runs the
agent on their own machine with their own credentials and their own key. Teammates **join** from
a terminal or a browser and watch every reply, tool call and diff as it happens, type prompts of
their own, and talk to each other without the agent ever seeing it.

Nothing the agent writes or runs reaches disk without the host's say: write and exec actions
always wait for approval, and a run started by a guest can never be waved through by a rule. That
one rule — **the host always decides** — is what the rest of these docs build on.

```bash
curl -fsSL https://raw.githubusercontent.com/Plural-Organization/Plural/main/install.sh | sh
cd your-project
plural
```

## The shape of a room

- **A shared live session.** The host runs the agent; guests join and see everything, live.
- **Two ways to prompt.** `open` mode lets everyone talk to the agent directly; `review` mode
  turns a guest's prompt into a proposal the host approves, edits or rejects.
- **Permission modes.** The host decides, at any moment, how much the agent may do without
  asking — from "ask before every change" to full `auto` mode.
- **Direct or relayed.** Connect over your own network, or through a relay that never decides
  permissions and never stores content.

Everything here describes the open-source `plural` CLI and `plural-host` — see the
[source on GitHub](https://github.com/Plural-Organization/Plural) for the code behind it.
